# Power BI Template App User Guide & Prerequisites

This template app provides pre-built dashboards and reports to help users analyze business data efficiently. It is designed for quick deployment with minimal setup.

---

## 1. Solution Overview

This template app provides pre-built dashboards and reports to help users analyze business data efficiently. It is designed for quick deployment with minimal setup.

### Key Features

- Pre-built Power BI dashboards
- Standardized data model
- Easy integration with your data sources
- Customizable reports

---

## 2. Prerequisites

Before installing the app, ensure the following requirements are met.

### Licensing Requirements

A Microsoft Power BI license is required. Any of the following will work:

- Power BI Pro, **or**
- Power BI Premium Per User (PPU), **or**
- Access to a Premium Capacity workspace

### Access and Permissions

- Access to **Power BI Service**
- Permissions to:
  - Install apps from the marketplace
  - Create or access a workspace
  - Configure dataset credentials

### Data Source Requirements

- Access to the required data sources, such as:
  - Fabric SQL Endpoints
- Required credentials (username/password or service account)

### Connectivity Requirements

- Internet access to connect to:
  - Power BI Service

---

## 3. Installation Steps

1. Go to **Microsoft AppSource / Marketplace**
2. Search for the app name
3. Click **Get it now**
4. Open in Power BI Service
5. Click **Install**

---

## 4. Configuration Steps

### Step 1: Connect Data

- Go to **Dataset Settings**
- Update data source credentials
- Select the authentication method

### Step 2: Configure Parameters

Enter the required values:

- Server name
- Database name

### Step 3: Refresh Dataset

- Perform a manual refresh
- Validate that data is loading correctly

---

## 5. Using the Reports

- Navigate through dashboards using tabs
- Use filters/slicers for analysis
- Drill down for detailed insights

---

## 6. Customization

Users can:

- Create additional reports
- Modify visuals
- Extend the data model

---

## 7. Troubleshooting

| Issue | Possible Cause | Resolution |
| --- | --- | --- |
| Data not loading | Incorrect credentials | Re-enter credentials |
| Missing data | Incorrect parameters | Validate configuration |
| Access denied | Permission issue | Contact admin |
